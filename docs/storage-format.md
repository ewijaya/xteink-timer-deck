# Storage format

Schema `v=1` follows PRD §8, with the baseline corrections in decisions.md. All stored values are integers, strings or tables. Tables are at most five levels below the root; the maximal-width fixture encodes to 9,123 bytes, below the 12,288-byte application budget and 16,384-byte platform limit.

Root fields: `rev` increases on save attempts, `next_id` is monotonic, `sel` is an item id or zero, and `trusted` is the last accepted whole-second clock sample. `set` contains appearance/style/default alert/count/flash/light/seconds/awake integers. `items` is a dense creation-ordered array of at most ten. `rc` holds the newest four import receipts first: signed CRC-32 `dig`, byte count `len`, number of created definitions `n`.

Item keys: `id` stable identity; `gen` run generation; `num` smallest free display number; `type` 0 countdown/1 stopwatch; `st` 0 Ready/1 Running/2 Paused/3 Finished; normalized ASCII `name`; `icon` 0–30; `pat/cnt` configured alert; `rpat/rcnt` captured alert; `att` consumed attempts; integer `sil/late/lim` flags; `dur` configured seconds; `val` frozen/accumulated seconds; `anc` running deadline or stopwatch segment start; `done` logical finish timestamp. Non-running item anchors are zero. Running countdown `val` remains positive as in the Pebble baseline; ticks never decrement it.

`ch.last` is the last chain id issued. `ch.saved` contains at most five definitions: id, revision, next step id, name, icon, rounds and 2–10 ordered steps. Steps have independent ids, name, icon, configured seconds and pattern. Total duration across all rounds cannot exceed MAX_SEC.

`ch.run` contains status (0 idle, 1 Running, 2 Paused, 3 Finished, 4 Stopped), source id, run generation, full definition snapshot, current index/round, anchor, logical boundary/result time, skips/away count, captured final pattern/count, attempts, pending cue flag and optional silence flag (missing means zero). Running anchors are step deadlines; Paused anchors are seconds left. The idle run retains its last generation to reject stale commands after Done. Snapshot depth is within the platform limit.

`core/const.add_time`, also exposed as `Model.add_time`, is the single checked deadline-add helper. Reconcile mutates an owned working copy; commands build and validate candidates without changing their input. The controller saves before success/effects. A failed user save preserves prior state. A failed time-driven save keeps a truthful in-memory view, displays NOT SAVED, holds effects and retries. Running state checkpoints every 300 seconds; the platform saves again at normal session end.

The private backup is `deck.bak`: `TDB1`, newline, signed decimal CRC-32 of the JSON bytes, newline, JSON. Atomic writes coalesce for two seconds after mutations and flush on leave. Load validates schema and all domain fields; valid backup recovery is explicit in the UI. A newer schema is blocked without overwriting it. Invalid state without a valid backup requires Try again or confirmed Start fresh; it is never silently repaired.
